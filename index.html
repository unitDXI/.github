The open-source home of Unit 511.

Unit 511 is Fairytale.ai’s open-source training, experimentation and development group. Our learning tracks are free and public, and every course ends with something you build and share. This page collects our public work on GitHub and explains how to take part.

Unit 511

What we do

Teach

Free learning tracks, published at unitdxi.fairytale.ai. Every course ends with an artifact you can show.

  • Languages and tools: HTML, CSS, JavaScript, SQL, Python, Java, R, C, C++ and Git, each its own track (coming soon)
  • AI Engineering: sixteen courses in four stages, from foundations and tooling to leadership and publishing

Build in the open

Notebooks, starter projects and small tools that support the curriculum are published here on GitHub under open licences, so anyone can run, inspect and improve them.

Publish

Cohort announcements, write-ups and releases go out on the Unit 511 blog. Lessons, including their code samples, are licensed CC BY-NC 4.0: reuse them non-commercially, with credit.

Community

Get involved

The curriculum site’s source is maintained privately, so all public contributions start here, as issues and discussions on this repository. Maintainers turn accepted proposals and fixes into site changes.

Report a problem

Found a factual error, a broken link or an unclear explanation in a lesson? Open an issue and pick the matching form.

Propose or write a lesson

Courses marked “Soon” on the curriculum need authors and reviewers. Use the Lesson proposal form to agree on scope before you write.

Contribute code

Our public tool and notebook repositories accept pull requests. Read the contributing guide first.

Learn with a cohort

Every course can be taken alone. Cohorts add a schedule, mentors and peer review. See Join a cohort.

Before you start

Ground rules

Free, public and vendor-neutral

Every example runs on free, public tools, with no paid API keys. When a lesson names a product or model, it names an alternative too. Teaching material never describes Fairytale.ai’s internal systems, tools or plans.

  • Code of Conduct. Everyone in Unit 511 spaces agrees to it. Read the code.
  • Security reports. Report vulnerabilities privately, never in a public issue. Read the security policy.
  • Licences. Lessons, including their code samples, and other written content are CC BY-NC 4.0: non-commercial reuse with credit. The curriculum site’s own code is proprietary. Code in our public tool and notebook repositories is MIT unless a repository says otherwise. See Licensing and attribution.
