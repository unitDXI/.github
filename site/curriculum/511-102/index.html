About this course#

Most AI work is ordinary software work: reading files, calling APIs, crunching arrays and making sure it all still works tomorrow. This course teaches the Python behind that work, with the habits that make code easy to share. You will use isolated environments, pinned dependencies, tests and clear packaging.

It suits people who have written a little code in any language. If you already know Python, skim the first two lessons and start at lesson 3.

Learning objectives#

By the end of the course you will be able to:

  • Set up reproducible Python environments with pinned dependencies
  • Load, clean and transform text and tabular data with the standard library
  • Use NumPy for vectorized numerical work
  • Call HTTP APIs robustly, with error handling and rate limiting
  • Test, type-check, profile and package a small tool

What you build: a tested command-line text-analysis tool#

You build a small command-line tool, one lesson at a time, that analyses text files. It counts words and estimated tokens, finds the most frequent terms, and compares documents by similarity. You will reuse it in later courses.

Your tool is complete when:

  1. It installs from its repository with pip install . and runs as a command with a useful --help.
  2. It reads one or more files, or standard input, and handles bad encodings and missing files with clear error messages.
  3. It reports word counts, an estimated token count, and the top N terms, as text or --json.
  4. It compares two documents and prints a similarity score computed with NumPy.
  5. It has a pytest suite with at least 80% line coverage, including tests that don’t touch the network or the real file system.
  6. It has a README with usage examples, a pinned requirements.txt and an open-source licence.
