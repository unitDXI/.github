About this course#

“AI” in the news usually means a system. It combines a model with a tokenizer, prompts, retrieved documents, tools, an inference runtime and an evaluation process. This course takes each of those parts apart and puts them back together, so you can reason about any AI product you meet, whoever built it.

You don’t need a machine-learning background, just some programming experience. Every example runs on free, public tools. When a lesson mentions a specific model or library, it names alternatives too.

Learning objectives#

By the end of the course you will be able to:

  • Explain how text is tokenized, embedded and generated by a language model
  • Run an open-weight model locally and measure its speed and cost
  • Build a small retrieval pipeline and a minimal tool-using agent
  • Evaluate a system’s outputs and describe its limits and failure modes
  • Choose models and data that fit a project’s licence and constraints

What you build: an annotated explainer notebook#

You build one notebook throughout the course, adding a section in every lesson. By the end it explains, in your own words and with code that runs, how an AI system turns a question into an answer. You can share it as a portfolio piece, and you can use it to teach someone else.

Your notebook is complete when:

  1. It runs top to bottom in a fresh Colab session with no errors and no paid API keys.
  2. It has one section per lesson, each with working code and at least one paragraph of explanation in your own words.
  3. It includes a tokenizer, a similarity search, a sampling demo, a retrieval example and a minimal agent loop.
  4. It ends with a “Limitations” section that names at least three ways the system you built could fail.
  5. It is published in a public repository under an open licence, with attribution for any course material you reused.
