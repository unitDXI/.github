Languages and tools#

Self-paced tracks that teach one language or tool each, from the first line of code. Start with HTML, CSS and JavaScript to build for the web; learn SQL, Python, Java, R, C or C++ for data and systems work; and learn Git to share what you build. They need no prior experience, and they are being written now.

Foundations & Tooling#

The tools and mental models everything else builds on: how AI systems work, Python, Git and open source, and the maths behind machine learning.

511-101 foundational

Introduction to AI Systems

How language models, embeddings, retrieval, agents and inference fit together, explained without tying you to any provider.

12 lessons · 12 hours · Builds an annotated explainer notebook

511-102 foundational

Python for AI Engineering

The Python you need to build, test and ship AI tooling: environments, data handling, NumPy, HTTP APIs and testing.

12 lessons · 12 hours · Builds a tested command-line tool

511-103 foundational

Git, Open Source & Contribution

How open source works and how to contribute well: Git from first principles, pull requests, licences, review and CI.

12 lessons · 12 hours · Builds a merged pull request

511-104 foundational

Math for Machine Learning

The linear algebra, probability and calculus behind modern models, built up in code you write yourself.

12 lessons · 12 hours · Builds a tested NumPy math toolkit
