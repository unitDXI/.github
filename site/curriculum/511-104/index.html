About this course#

You don’t need a maths degree to understand how models learn, but you do need a few ideas very clearly: vectors, matrices, probability and gradients. This course teaches them the way engineers use them. Each idea is introduced visually, then implemented in plain Python, then checked against NumPy. Formulas always come with code that runs.

It assumes comfort with basic Python (511-102 lessons 1–7) and school algebra. Calculus is introduced from scratch.

Learning objectives#

By the end of the course you will be able to:

  • Work with vectors and matrices, and read their shapes and meaning
  • Compute and interpret dot products, norms and similarity measures
  • Reason about probabilities, distributions and expectations
  • Compute gradients and implement gradient descent
  • Implement softmax and cross-entropy in a numerically stable way

What you build: a from-scratch math toolkit#

Lesson by lesson, you write a small Python library that implements the operations models depend on. You then prove it correct against NumPy.

Your toolkit is complete when:

  1. It implements vector arithmetic, matrix multiplication, norms, cosine similarity, a stable softmax, cross-entropy, a numerical gradient check and gradient descent.
  2. The core functions use only the Python standard library. NumPy is used only in tests.
  3. Its tests compare every function with NumPy on randomly generated inputs, agreeing to within 1e-9.
  4. Each function has a docstring stating the formula it implements and its input shapes.
  5. It installs with pip install . and ships under an open-source licence.
