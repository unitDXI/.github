Glossary#

Artifact
The thing a course has you build and publish: a notebook, tool, library, document or merged contribution.
Context window
The maximum number of tokens a model can take into account at once, including both the prompt and the output.
Cosine similarity
A measure of how closely two vectors point in the same direction, from −1 to 1. Widely used to compare embeddings.
Embedding
A vector that represents a token, word or passage so that similar meanings are close together.
Inference
Running a trained model to produce outputs, as opposed to training it.
Open-weight model
A model whose trained parameters are published for download. Its licence may still restrict how it can be used.
Quantization
Storing a model’s numbers at lower precision to reduce memory use and speed up inference, usually at some cost in quality.
Retrieval
Finding relevant documents, often by embedding similarity, and supplying them to a model as context.
Token
The unit of text a model reads and writes. Usually a word or part of a word, mapped to an integer ID by a tokenizer.
Tokenizer
The component that splits text into tokens and maps them to IDs. It must match the model it is used with.
