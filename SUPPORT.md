# Getting help

## Where to go

| Question | Where |
|:--|:--|
| How do I start? Which course first? | The [curriculum](https://unitdxi.fairytale.ai/site/curriculum/). For AI Engineering, start with 511-101 |
| How do I solve this exercise? | Ask in [Discussions](https://github.com/orgs/unitDXI/discussions), with what you tried |
| A lesson has a mistake, or a page is broken | [Open an issue](https://github.com/unitDXI/.github/issues/new/choose) |
| I'd like to write or review a lesson | Open a *Lesson proposal* issue |
| Cohorts and applications | The [Join a cohort page](https://unitdxi.fairytale.ai/site/cohorts/) and the [blog](https://unitdxi.fairytale.ai/site/blog/) |
| A security problem with our site or repositories | The [security policy](SECURITY.md). Never a public issue |
| Behaviour that breaks the Code of Conduct | Contact a maintainer privately. See the [Code of Conduct](CODE_OF_CONDUCT.md) |

## What we can't help with

- Debugging your own projects that aren't part of a Unit 511 course. Discussions is a good place to ask other learners, but maintainers may not answer.
- Paid services, API keys or accounts with third-party providers. Our examples never need them.
- Certification or exam questions.

## Response times

Unit 511 is run by a small team. We aim to triage new issues within a week. Security reports are acknowledged within five working days.
